# fe-test-bees
Frontend technical test for BEES. Includes a logic function and a user management table.


LOGIC
- Adds a 1-second delay between each number
- Handles empty arrays gracefully
- Validates input types and throws a custom error
- Clean and modern syntax using `async/await`

USER TABLE
- Display user info in a paginated table
- Edit user details via a modal popup
- Delete users with a single click
- Add new users
- Pagination (default: 10 rows per page, changeable)
- Format currency with `$` and thousands separators
- Email displayed as clickable mailto links
- Show registration date as `yyyy-MM-dd` with tooltip for full datetime
